# 評価（引き継ぎ書 §7）

## 原則

- 評価セット `questions.yaml` は **Knowledge 投入前（Phase 3）に凍結** する。凍結後は変更しない。
- RAG 無しの素の Qwen3.8-27B で基準値を先に取り `baseline/` に置く。
- 変更は一度に一つだけ。実行結果は `runs/YYYYMMDD-<label>/` に置く。

## 構成（30 問）

| 種別 | 数 | 内容 |
|---|---|---|
| factual | 15 | 著作の内容、成立年、上表の相手など正解が確定するもの |
| attribution | 5 | 本人の言葉か後世解釈かの区別 |
| trap | 10 | 架空著作名、later_attribution の引用誘導、大乗一般思想の空海帰属誘導 |

## ホールドアウト

episodes のうち 3〜5 件を伏せ、状況だけを与えて判断の方向が一致するかを見る。

## 指標

架空引用率、引用実在率、trap 正しい拒否率、ホールドアウト判断一致率。
