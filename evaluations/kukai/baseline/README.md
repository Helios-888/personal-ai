- **天井効果に当たる。** B1 の trap 正しい拒否は 10/10（両採点とも）。設計書の決めどおり、Phase 4 の全体成功基準は「trap 拒否数が下がらず、かつ factual 正答が 2 問以上増える」に読み替える。
- **B1 の 10/10 は「何でも断る」ことと切り離せない。** 過剰拒否が 20/45 あり、F11『三教指帰』・F12『性霊集』の問いは 3 回とも「著していない」と退けた。設計書「着手時に判明したこと」2 で予想した、目録の一文による過剰拒否が実際に起きた。
