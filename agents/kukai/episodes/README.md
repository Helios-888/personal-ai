# episodes（判断様式の層）

空海が「その場面でどう決めたか」を一件ずつ記した自作文書。引き継ぎ書 §3.2 の三層構成のうち「判断様式」に当たる。

- ここから抽出した判断原則 5〜10 項目を `../principles.md` に置き、**それだけを常時層（システムプロンプト）に載せる**。episodes 本体は常時層に入れない（1 件 400〜600 字 × 8 件で予算 5,000 トークンを圧迫するため）。
- Phase 4 で Knowledge に投入するかは、そのとき決める。投入する場合も `holdout/` は除く。

## ホールドアウト（Phase 3 の人格層評価）

`holdout/` に置いた 3 件は**伏せる**。常時層にも Knowledge にも入れない。principles.md の抽出元にもしない。評価時は「状況」節だけを問いとして与え、「判断」節と方向が一致するかを見る（引き継ぎ書 §7）。

伏せた件の判断が原則として常時層に漏れると、ホールドアウト試験は「覚えているか」を測るだけの試験になり無効化する。執筆の順序は必ず「伏せる件を先に決める → 残りから principles を抽出する」とする。

## 書式

frontmatter に事実の出典と信頼区分を、本文に「状況・判断・根拠・検証が要る点」を書く。

```yaml
---
id: ep-kukai-0002          # ep-<agent>-<連番4桁>
title: 恵果からの伝法と早期の帰国
year: 805                  # 出来事の年。幅があるときは開始年
holdout: false             # true なら holdout/ に置く
principle: 授かった法は、身の安全より先に世へ渡す   # principles.md への抽出候補（1 行）
fact_reliability: primary_text   # 下の「事実の区分」から選ぶ
sources:                   # 事実の出所。書名と、そこに何が書かれているか
  - 『御請来目録』（空海自身の上表。請来した経典・法具の一覧と帰国の経緯）
verify:                    # 利用者に検証してもらう点。数字・人名・書名を具体的に
  - 灌頂の月次
---
```

### 事実の区分（`fact_reliability`）

`knowledge/_schema/metadata.yaml` の `reliability` と同じ語を使う。episode の**地の文は自作**だが、そこに書く事実がどこまで遡れるかを示す。

| 値 | この episode での意味 |
|---|---|
| `primary_text` | 空海自身の著作・書簡に記述がある |
| `academic_research` | 同時代の史書・公文書、または研究で定説とされる |
| `later_attribution` | 後世の伝記・伝承にしかない。**判断の根拠にしてよいが、本人の言葉として引用させない** |

一つの episode に区分の違う事実が混ざるときは、最も弱い区分を frontmatter に書き、強い事実には本文で個別に出典を添える。

## 検証の手順

執筆者（AI）は事実を確定できない。`verify` に挙げた点を利用者が確認し、誤りがあれば本文と frontmatter を直す。**確認が済むまで principles.md へ抽出しない。**
